# How cusage works

cusage as you use it, one page per feature. It describes what works now. What's planned is in the
briefs (`docs/briefs/`), and how the code is built is in `docs/architecture/`.

Start with [The archive](the-archive.md): everything else reads what it keeps.

- [The archive](the-archive.md): installing, `sync`, the two background agents, `status` and
  `doctor`, and where the archive lives.
- [Limits](limits.md): `cusage limits`, the limit the tray doesn't show, `--history`, refreshing,
  and the statusline.
- [Sessions](sessions.md): one chat's breakdown, listing and grouping chats, and attribution by
  agent, skill, MCP server or tool.
- [Cost](cost.md): measured and estimated cost, and what `$`, `~$`, `+` and "unavailable" mean.
- [Over time](over-time.md): daily, weekly and monthly totals, observed five-hour cycles, and
  cache ratios.
- [Scripting](scripting.md): `--json`, `--csv`, `export`, filters and exit codes.
- [The explorer](explorer.md): `cusage-tui`, its five tabs and their keys, theme and refresh.
- [Trusting the numbers](trusting-the-numbers.md): what the data can and can't tell you, and
  what cusage will never do.
