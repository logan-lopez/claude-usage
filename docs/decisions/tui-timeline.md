# TUI Timeline

## Choice

Bars of output tokens with a ▲ cursor; the split by model, project or effort is a table of the cursor's bucket, not stacked bars; no cost column; one book-comparison line at the top

## Why

Cache reads are 97.9% of total tokens, so total bars chart context size. 365 projects and the WCAG palette test rule out per-series colours. Cost by day reads $0.00 today. (Logan, 2026-10-28, brief 08)
